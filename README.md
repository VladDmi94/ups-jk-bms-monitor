# Windows UPS Monitor for JK BMS (Go)

Легковесный сервис на Go для превращения аккумулятора с **JK BMS (BD4A8S4P)** в полноценный ИБП (UPS) для Windows.

Скрипт подключается к BMS по Bluetooth Low Energy (BLE), считывает телеметрию в режиме пассивного стриминга (без лишних писков зуммера), рассчитывает оставшееся время работы, отправляет уведомления в Telegram при отключении/возобновлении питания и автоматически завершает работу Windows при критическом разряде.

---

## ⚡ Особенности

- **Пассивный BLE-стриминг (`JK02_32S`)**: Инициализация выполняется командами `0x97` и `0x96`, после чего плата вещает данные автономно. Зуммер BMS больше не пищит каждые N секунд.
- **Детекция питания с гистерезисом**: Порог тока разряда установлен в `-0.1 A`, чтобы исключить ложные срабатывания от микротоков балансировки или шумов датчика.
- **Расчёт автономного времени**: Время работы высчитывается динамически на основе текущего тока разряда и реального SOC (%):
  
  $$\text{Remaining Ah} = \text{Capacity} \times \frac{\text{SOC}}{100}$$
  $$\text{Run Time (hours)} = \frac{\text{Remaining Ah}}{\vert{}\text{Discharge Current}\vert{}}$$

- **Telegram Уведомления**: Гибкая настройка задержки отправки (`DELAY_NOTIFY`), чтобы не спамить в чат при кратковременных скачках напряжения.
- **Автоматическое выключение ПК**: При достижении порога `SHUTDOWN_THRESHOLD` (например, $\le 10\%$) инициирует корректное завершение работы Windows (`shutdown /s /t 30`).
- **Логирование**: Параллельный вывод событий в консоль и локальный файл `ups_log.txt`.

---

## 🛠 Требования

1. **ОС**: Windows 10 / 11 (с поддержкой Bluetooth LE).
2. **Аппаратная часть**: JK BMS (проверено на `BD4A8S4P`, HW `15H`, SW `15.41`).
3. **Go**: Версия `1.20+` (используется библиотека [`tinygo.org/x/bluetooth`](https://github.com/tinygo-org/bluetooth)).

---

## ⚙️ Настройка конфигурации (`.env`)

Создайте файл `.env` в корневой директории проекта рядом с `main.go` или бинарным файлом:

```env
TARGET_BMS_NAME=YOUR_BMS_NAME_HERE
BATTERY_CAPACITY_AH=YOUR_BATTERY_CAPACITY_HERE_IN_AMPERE_HOURS
TELEGRAM_TOKEN=YOUR_BOT_TOKEN_HERE
TELEGRAM_CHAT_ID=YOUR_CHAT_ID_HERE
DELAY_NOTIFY=5            # Задержка перед отправкой алерта в Telegram (в секундах)
SHUTDOWN_THRESHOLD=5      # Порог SOC (%) для аварийного выключения Windows
SHUTDOWN_TIMEOUT=30       # Тайм-аут перед выключением Windows (в секундах)
LOG_FILE=ups_log.txt

```

## 📌 Архитектура кадра данных (`JK02_32S`)

Кадр телеметрии `0x02` имеет фиксированный размер **300 байт**. Проверка целостности выполняется по младшему байту суммы первых 299 байт (`Sum8 CRC == frame[299]`).

### Кадр метаданных (Frame `0x03` — Device Info)

| Параметр | Смещение (Байты) | Тип данных | Описание |
| :--- | :--- | :--- | :--- |
| **Модель устройства** | `6 : 21` | `string` (ASCII, null-trimmed) | Название модели (напр., `JK_BD4A8S4P`) |
| **Ревизия железа (HW)** | `22 : 29` | `string` (ASCII, null-trimmed) | Версия планера/HW (напр., `15H`) |
| **Версия прошивки (SW)** | `30 : 37` | `string` (ASCII, null-trimmed) | Версия ПО (напр., `15.41`) |

### Кадр телеметрии (Frame `0x02` — Status Telemetry)

| Параметр | Смещение (Байты) | Тип данных | Множитель | Ед. изм. |
| :--- | :--- | :--- | :--- | :--- |
| **Напряжение ячеек 1..8** | `6 + (i * 2) : 7 + (i * 2)` | `uint16` (LE) | `0.001` | V |
| **Напряжение сборки (Total V)**| `150 : 153` (`118+32`) | `uint32` (LE) | `0.001` | V |
| **Ток (Current)** | `158 : 161` (`126+32`) | `int32` (LE) | `0.001` | A |
| **Температура MOS** | `144 : 145` | `int16` (LE) | `0.1` | °C |
| **Температура T1** | `162 : 163` | `int16` (LE) | `0.1` | °C |
| **Температура T2** | `164 : 165` | `int16` (LE) | `0.1` | °C |
| **Уровень заряда (SOC)** | `173` | `uint8` | `1.0` | % |
| **Чексумма (CRC)** | `299` | `uint8` | `Sum8(frame[0..298])` | — |
